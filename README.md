# AGRO NOVA — Возрождение долины

Новая браузерная 3D-игра про сельскохозяйственный дрон. TypeScript, Three.js, Vite, WebGL 2. Вся графика и звук создаются процедурно: внешних CDN, платных ресурсов и ключей API нет.

## Запуск

Нужен Node.js 22.12+ или 24 и современный браузер с WebGL 2.

```bash
npm install
npm run dev
```

Откройте адрес, который напечатает Vite. Для воспроизводимой установки используйте `npm ci` вместо `npm install`.

```bash
npm test          # Проверки полёта, контрактов, ресурсов и сохранений
npm run build    # TypeScript и production-сборка в dist/
npm run preview  # Локальная проверка production-сборки
```

`dist/` можно разместить на статическом HTTP-сервере. HTML необходимо открывать через сервер: ES-модули не рассчитаны на запуск двойным щелчком через file://.

## Первый вылет

Начните новую игру. Удерживайте **Пробел**, чтобы подняться выше 5 метров. Нажмите **C** для смены камеры, затем **Shift**, чтобы мягко сесть на ту же площадку. После результата переходите к следующему контракту.

Пшеничное поле находится к северо-западу от базы. Выберите сканер, нажмите на 3D-сцену для захвата мыши и удерживайте ЛКМ, облетая поле. Тепловые цвета соответствуют влажности и состоянию реальных ячеек поля. Затем выберите орошение и летайте параллельными полосами на высоте **1–12 м**. Подержите распылитель над пропущенными участками: короткого касания недостаточно для качественной обработки.

Вода пополняется клавишей **F** у насосной станции, в 40 м к востоку от базы, на высоте менее 4 м и скорости менее 3 м/с. Аккумулятор автоматически заряжается на посадочной площадке. В режиме посева используется гидропосевная смесь из того же резервуара. Ангар доступен после посадки на базе.

## Управление

| Клавиша | Действие |
| --- | --- |
| WASD / стрелки | Движение относительно камеры |
| Пробел / Shift | Набор высоты / снижение |
| Мышь | Поворот камеры после щелчка по сцене |
| ЛКМ | Удерживать для работы инструмента |
| ПКМ | Приближение камеры |
| 1 / 2 / 3 | Сканирование / орошение / гидропосев |
| C | Камера за дроном / сверху / FPV |
| F | Заправка, зарядка, запуск комплекса или аварийная эвакуация |
| H | Ангар на базе |
| M / Tab | Карта / описание контракта |
| Esc | Освободить мышь / пауза |
| T / P | Переключить время суток / погоду для исследования сцены |

После потери фокуса клавиши сбрасываются. Esc освобождает мышь и ставит игру на паузу. Кнопки интерфейса доступны при освобождённой мыши.

## Реализованные системы

- Долина 600 × 600 м: поля пшеницы, кукурузы и подсолнечника, участок под посев, река и водоём, лесополосы, ферма, агрокомплекс, дороги и мост.
- Инстансинг десятков тысяч растений, ветер и поток от роторов, рост и изменение цвета культур, влажность почвы, шейдерная вода и облака.
- PBR-материалы, ACES, освещение окружения, динамические тени, SSAO, bloom и четыре действующих пресета качества.
- Дрон с четырьмя роторами, баком, камерой, форсунками, навигационными огнями и двумя конфигурациями. Инерция, стабилизация высоты, влияние ветра и массы жидкости, столкновения, аварийная посадка.
- Три инструмента, реальные ячейки состояния полей, пять контрактов, оценка покрытия, штраф за обработку вне полей, награды и шесть улучшений.
- Цикл дня, погода с переходами, дождь и гроза, движущийся трактор, птицы, вечернее освещение, активация комплекса в финале.
- Процедурный звук двигателей, ветра, дождя, распыления, птиц и интерфейса. Звук включается после действия пользователя.
- Автосохранение каждые 12 секунд и при выходе, ручное сохранение, настройки. Версионирование, проверка структуры и контрольная сумма; предыдущий корректный снимок сохраняется в резерве. Неизвестные версии и повреждённые данные не перезаписываются.

## Структура

- `src/core` — игровой цикл и общие определения.
- `src/render` — рендер, атмосфера, частицы и Web Audio.
- `src/world` — рельеф, растительность, вода и постройки.
- `src/drone` — модель, физика, ввод и камеры.
- `src/systems` — поля, контракты, экономика и сохранения.
- `src/ui` — русскоязычный интерфейс.
- `tests` — проверки реальных игровых правил и полёта.
- `public/reference/original.html` — исходный приложенный HTML, сохранённый побайтно без изменений. Новая игра его не импортирует.

## Границы реализации

Это самостоятельная компактная игра с кампанией из пяти контрактов, а не коммерческий симулятор сельского хозяйства. Полёт и столкновения упрощены; погода и агрономия используют игровые модели. Нет мультиплеера, сбора и продажи урожая, физических отражений всей сцены в воде, настоящих объёмных облаков или внешней HDR-карты. Окружение, звук и материалы процедурные. Сохранения локальны для браузера и адреса сайта.

HIGH — исходное качество. LOW отключает SSAO и bloom и уменьшает разрешение теней; ULTRA увеличивает разрешение и тени. Скорость зависит от видеокарты, браузера и разрешения. Гарантия 60 FPS не заявляется.

## Фактическая проверка

Проверены 14 автоматических тестов и сквозной сценарий в Chromium: старт из меню, взлёт настоящим клавиатурным вводом, смена камеры, посадка и награда, продолжение завершённого контракта, работа сканера и полива, смена погоды и времени, реальные параметры LOW/ULTRA и восстановление обработанного поля после перезагрузки. Ошибок JavaScript или компиляции шейдеров в финальном сквозном запуске не было.

Все пять контрактов дополнительно исполняются автоматическим тестом через реальные операции симуляции. В Chromium пройдено обучение и проверена обработка пшеницы; полная кампания вручную в браузере не проходилась. Производительность на игровой видеокарте не измерялась: в облачной проверке использовался медленный программный GPU SwiftShader.

Повторить браузерный сценарий можно при установленном Python-пакете `playwright` и Chromium:

```bash
npm run dev
# В другом терминале:
python scripts/browser-smoke.py
```

По умолчанию браузерный тест использует `/usr/bin/chromium`; путь можно задать переменной `CHROMIUM_PATH`. Результат и реальные кадры сохраняются в `artifacts/`. Тест использует отдельный профиль браузера и LOW для программного GPU.

Локально включённые шрифты Open Sans распространяются с лицензией в `src/ui/fonts/LICENSE.txt`.

Production-сборка также проверена через `npm run preview`: старт из меню и взлёт клавиатурой работают, ошибок JavaScript/WebGL нет, отладочный API исключён из сборки. `python scripts/render-smoke.py` отдельно проверяет реальные кадры HIGH, ночь, грозу и шейдер частиц посева. Лицензии шрифтов и Three.js включены в `public/THIRD_PARTY_NOTICES.txt` и готовую сборку.
