# АЭРОЛАБ

**Интерактивная лаборатория беспилотных авиационных систем.** Локальная образовательная платформа: каталог → комплектация → обновление 3D → расчёт → сохранение → сравнение. Без сервера, регистрации, внешних API, игровых механик и коммерческих разделов.

## Запуск

Node.js 22.12+ или 24+:

```bash
npm install
npm run dev
```

В облачной среде с недоступным домашним кэшем используйте `npm ci --cache /workspace/.npm-cache`. Для воспроизводимой установки локально — `npm ci`.

```bash
npm test           # 12 проверок расчётов, конструкции и валидации
npm run build      # TypeScript + production-сборка в dist/
npm run preview    # Сервер production-сборки
```

Для 3D нужен WebGL 2. Все ресурсы, включая шрифты, поставляются локально. Vite по умолчанию использует порт 5173, preview — 4173. Файлы `dist/` подходят для статического хостинга; открывайте приложение через HTTP, а не file://.

## Что работает

- Шесть разделов: главная, каталог, конфигуратор, цифровая модель, сравнение, проекты.
- Восемь демонстрационных платформ: AGRO A6, CARGO X8, GEO MAPPER, RESCUE R4, INSPECT S4, WING SURVEY, HYBRID V1, ECO SENSOR. Это условные учебные аппараты, не модели серийных изделий.
- Каталог: поиск по названию, описанию и назначению; фильтры конструкции, направления, числа двигателей, массы и предела полезной нагрузки.
- Уникальные процедурные 3D-конструкции: гексакоптер с баком и распылением; октокоптер с грузом; компактный картографический аппарат; спасательный с тепловизором и прожектором; инспекционный с защитой; самолёт с крылом, хвостом и толкающим винтом; VTOL с четырьмя подъёмными и одним маршевым двигателем; экологический с измерительными блоками.
- Конфигуратор показывает только совместимые компоненты. Меняются аккумуляторы, камеры, сенсоры и модули. Специальные настройки: объём и заполнение бака, форсунки, груз, крепление, размах крыла, защита винтов.
- Геометрия и показатели обновляются одновременно. Масса воды входит в общую массу; масса пустого бака зависит от объёма.
- Цифровая модель: обычный вид, прозрачный корпус, анимированное разнесение, цвета массовых групп, техническая схема с размером и осями. Клик по компоненту или списку открывает инспектор с его параметрами. Доступны четыре ракурса, вращение, масштаб и полноэкранный режим (Escape — выход).
- Сравнение до четырёх базовых платформ или сохранённых конфигураций: таблица, только различия, интерактивная диаграмма с выбором показателя. Сохранение изменений существующего проекта обновляет сравнение.
- Проекты: создание, сохранение, открытие, переименование, копирование, удаление с подтверждением, экспорт и проверяемый импорт JSON. localStorage хранит конфигурации после перезагрузки. Важные проекты рекомендуется экспортировать; при недоступном хранилище показывается предупреждение.
- Адаптивный интерфейс с мобильным меню и компоновкой панелей в одну колонку. На телефоне модель расположена перед параметрами.

## Учебные расчёты и допущения

Единственный источник данных — `src/lab/data.ts`. У компонентов заданы ID, категория, масса (кг), размеры (м), мощность (Вт), совместимость и описание. Дополнительные поля аккумуляторов: напряжение и ёмкость; камер: разрешение; баков: объём и плотность; креплений: тип подвеса. Массы силовых и конструктивных элементов генерируются здесь же по платформе.

- Общая масса — сумма всех установленных элементов, жидкости и груза.
- Полезная нагрузка — рабочие, съёмочные и измерительные модули, бак и насос, жидкость, площадка и груз. Силовая установка, рама, опоры и аккумулятор сюда не входят.
- Номинальная энергия: `E = U × C` (Вт·ч). Доступно 80%; оставшиеся 20% — условный резерв.
- Учебная мощность: `P = Pбаз × (m / mопорная)^a × k + Pоборудования`. Для мультикоптеров `a = 1,5`, для самолёта и VTOL в крейсерском режиме — `a = 1`. Базовая мощность и опорная масса различаются по платформам. Сценарии: `k = 0,8 / 1 / 1,3`. Вспомогательные системы условно включены постоянно.
- Оценка времени: `t = Eдоступная / P × 60` минут. Это оценка работы при заданной мощности, не подтверждённая продолжительность полёта.
- Центр масс: `Σ(mᵢ × rᵢ) / Σmᵢ` в системе координат центральной рамы. Y направлена вверх; X — поперёк, Z — вдоль аппарата. Разнесение — способ просмотра: оно не меняет расчётную компоновку.
- Для воды принято `1 л = 1 кг`. Показатель «с полным баком» не зависит от текущего процента заполнения.
- Резерв груза ограничен одновременно заданной взлётной массой и пределом нагрузки. При превышении любого ограничения выводится предупреждение.
- Габариты условные, по платформе; у самолётных аппаратов учитывается выбранный размах. Геометрия и компоновка схематичны, не CAD для изготовления.

Не рассчитываются аэродинамика, устойчивость, фактическая тяга, реальные параметры GNSS, ветер, температура, КПД силовой установки, изменение массы жидкости во времени, переходные режимы VTOL. Здесь нет фиктивной телеметрии и управления реальным аппаратом. Цифровая модель не является подтверждённым двойником серийного БПЛА.

## Проверка в браузере

Нужны Python Playwright и Chromium. В среде разработки они уже доступны; для своей машины установите `python3 -m pip install playwright` и Chromium с системными библиотеками.

В одном терминале `npm run dev`, в другом:

```bash
python3 scripts/browser-smoke.py
```

Можно задать `CHROMIUM_PATH` и `AEROLAB_TEST_URL`. Сценарий использует отдельный профиль браузера, проверяет каталог, реальное изменение WebGL-изображения бака, расчёты, сохранение после reload, груз, аккумулятор, режимы модели, инспектор, сравнение, операции над проектами и мобильную ширину 390 px. Скриншоты и отчёт пишутся в игнорируемый `artifacts/aerolab/`. На программном GPU отрисовка медленнее, производительность игровой видеокарты не заявляется.

## Структура

- `src/lab/data.ts` — платформы, библиотека компонентов, компоновка, расчёты, валидация импорта.
- `src/lab/store.ts` — Zustand, проекты, localStorage, экспорт.
- `src/lab/Scene.tsx` — React Three Fiber / Drei, процедурная геометрия, ракурсы и режимы.
- `src/lab/App.tsx` — разделы, панели, модальные окна, сравнение Recharts.
- `src/lab/style.css` — адаптивная тема и Tailwind CSS.
- `tests/engineering.test.ts` — расчёты и ограничения.

React, TypeScript, Vite, Three.js, React Three Fiber, Drei, Tailwind CSS, Lucide React, Recharts, Zustand. Локальные шрифты Open Sans: лицензия в `src/ui/fonts/`. Уведомления сторонних библиотек — `public/THIRD_PARTY_NOTICES.txt`.
